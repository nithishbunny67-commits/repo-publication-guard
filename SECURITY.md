# Security policy

This tool is a best-effort pre-publication check and makes no claim of exhaustive secret detection.

If you discover an issue, please open a GitHub issue **without posting real credential values, complete sensitive files, or exploitable personal information**. Until a private security-reporting channel is configured on GitHub, do not post unredacted vulnerabilities to public issues; contact the repository maintainer privately through an appropriate channel.

If a real secret has been committed, revoke or rotate it immediately. Removing it from the working tree does not erase Git history.
